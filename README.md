# Лабораторна робота №7

## Тема
Робота з файлами. Серіалізація.

## Мета роботи
Закріпити навички роботи з файлами CSV та XLSX у Python, а також використання бібліотек Faker, pandas та openpyxl.

## Використані бібліотеки
- Faker
- pandas
- openpyxl
- matplotlib

## Структура проекту
- create_csv.py — створення CSV файлу
- create_xlsx.py — створення XLSX файлу
- analytics.py — аналіз даних та побудова діаграм
